# Simple Math Exercises in C# (WPF)

This repository contains a few small math-related exercises I created while learning C# and WPF. These are part of my early programming practice, and I'm sharing them to document my learning progress. Each exercise focuses on basic logic and user interaction.

## Projects

### 1. math-klas-oefening1
A basic math input example, possibly checking a calculation or displaying a result based on user input. (Details depend on project content.)

### 2. math-klas-oef2
Another simple math-related WPF project. It uses basic UI controls and conditionals to respond to user input.

### 3. math-klas-oef3
Yet another small math application, continuing from oef2 with slightly different logic or layout.

> All projects use basic WPF components like `TextBox`, `Label`, and `Button`. The main focus is to learn how to handle events (`Click`), retrieve input, and display results using simple C# logic.

## Notes

- These are beginner-level projects made as part of a programming course.
- No advanced error handling or validation is included.
